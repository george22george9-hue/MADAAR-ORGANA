# ⛪ ORGANA | أورجانا
### منظومة إدارة خدمة الكنيسة ومدارس الأحد
**كنيسة الشهيد العظيم مارجرجس بسندبيس** — مطور بواسطة **MADAAR Technologies**

---

## 🌟 نبذة عن المنظومة
**أورجانا (ORGANA)** هي منظومة كنسية متكاملة مصممة لإدارة خدمة مدارس الأحد والافتقاد والمتابعة الروحية لكنيسة الشهيد العظيم مارجرجس بسندبيس. تهدف إلى تحويل إدارة الخدمة الكنسية إلى تجربة رقمية منظمة وسلسة، تحفظ خصوصية وسرية البيانات الرعوية، وتدعم العمل من أي هاتف أو حاسوب عبر الويب وتطبيق الـ PWA.

---

## 🏛️ الهيكل الإداري والرتب الكنسية (RBAC)
1. **مسؤول إدارة المنظومة (Admin)**: التحكم الكامل في الإعدادات، وأمان النظام، وتعيين الكهنة وأمناء الخدمة.
2. **الآباء الكهنة (Priests)**: الإشراف الروحي الشامل، والاطلاع على كافة الأسر، وتفقد أحوال الخدمة والاعتراف.
3. **أمين عام الخدمة (Service Secretary)**: المتابعة الإدارية الشاملة، مراجعة كشاكيل الخدمة، واعتماد تقارير الجمعة.
4. **أمناء الأسر (Family Leaders)**: إدارة أسرة معينة من أسر الكنيسة العشر، تسجيل مشاركات الخدام، وتوزيع المهام.
5. **خدام الأسر (Servants)**: متابعة مخدومي الأسرة، تسجيل الحضور، والافتقاد الدوري.

---

## 📋 الأسر الكنسية المعتمدة (10 أسر)
1. أسرة الملاك ميخائيل (حضانة بنين وبنات)
2. أسرة الشهيد فيلوباتير مرقوريوس - أبي سيفين (ابتدائي بنين)
3. أسرة الشهيدة دميانة (ابتدائي بنات)
4. أسرة البابا كيرلس السادس (إعدادي بنين)
5. أسرة الشهيدة مارينا (إعدادي بنات)
6. أسرة القديس أثناسيوس الرسولي (ثانوي بنين)
7. أسرة القديسة فيرينا (ثانوي بنات)
8. أسرة القديس حبيب جرجس (جامعيين وخريجين)
9. أسرة الأنبا أنطونيوس (إعداد خدام)
10. أسرة القديس يوسف النجار (خدام وخادمات الكنيسة)

## ✨ المميزات الرئيسية
- 📅 **ملف لكل جمعة بالتاريخ**: تقويم كامل لجميع جمعات العام الكنسي مع حفظ نسب الحضور والغياب.
- 👥 **مربعات اختيار الخدام (4 مهام)**: (شرح افتتاحية - ورش عمل - تحضير - شرح الدرس).
- 🕊️ **مربعات اختيار المخدومين (4 أركان)**: (قداس - تناول - فصل - الاعتراف).
- ⚠️ **تنبيه رعوي عاجل للاعتراف**: تنبيه تلقائي فوري لخدام الأسرة إذا لم يعترف المخدوم لمدة 4 أسابيع متتالية.
- ⛪ **خانة أب الاعتراف**: مدونة في الملف الشخصي لكل رتبة وشخص بالمنظومة.
- 📱 **دعم تطبيق الهاتف (PWA)**: إمكانية التثبيت المباشر على شاشة الهاتف الرئيسية لأجهزة Android و iPhone.
- 📊 **تصدير كشوفات وطباعة**: تصدير مباشر إلى ملفات Excel وطباعة PDF رسمية بختم الكنيسة.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Frontend & Fullstack**: Next.js 14 (App Router) + React 18 + TypeScript
- **Styling**: Tailwind CSS + Lucide Icons (هوية كنسية بلون المارون الخمري `#702C3B`)
- **Database**: 
  - محلياً: SQLite مع Better-SQLite3
  - سحابياً: PostgreSQL / Supabase
- **Hosting & Tunneling**: Cloudflare Tunnel / Vercel / Railway
